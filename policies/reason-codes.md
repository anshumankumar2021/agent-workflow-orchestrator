# Chargeback reason codes

| Code | Meaning | Typical evidence |
|---|---|---|
| 10.4 | Fraud - card-absent environment | 3-D Secure authentication record, AVS/CVV match, device fingerprint |
| 12.6 | Duplicate processing | Proof the two transactions were for separate purchases |
| 13.1 | Merchandise or services not received | Delivery confirmation with date and address |
| 13.3 | Not as described or defective | Product description, customer communication, return policy |
| 13.7 | Cancelled merchandise or services | Cancellation policy shown at checkout, proof the customer did not cancel |

Fraud codes (10.x) count toward the fraud monitoring program as well as the chargeback ratio.
